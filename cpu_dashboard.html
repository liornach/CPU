Extended SAP-1

A Simple-As-Possible-1 core (Malvino & Brown) stretched to an 8-bit address bus and a memory-mapped ASCII output port, so it can run programs like an unrolled “Hello, World!” instead of just driving a 7-segment digit.

Implementation status: only the six primitive gates below are built and tested today (include/gates/ — NandGate, NotGate, AndGate, OrGate, NorGate, XorGate). Everything in the schematic below — registers, the ALU, the control unit, the buses — is the target design those gates are meant to be assembled into, not code that exists yet.
